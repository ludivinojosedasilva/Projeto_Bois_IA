

## Dataset de Segmentação — YOLOv8

Dataset utilizado no treinamento do modelo de segmentação de instância (YOLOv8s-Seg).

## Conteúdo

Imagens de bovinos em vista traseira e lateral, anotadas com polígonos de segmentação no formato YOLO (.txt).

## Tamanho

Aproximadamente 10 GB — 6.009 imagens de treino + 1.503 de validação após limpeza.

## Por que não está no Git

O volume de imagens excede o limite prático do GitHub. O dataset fica armazenado no Google Drive.

## Como obter


[Download do Dataset — Google Drive](https://drive.google.com/drive/folders/1boL66L-WAygt3hamhRuMsGGq_l5gSfcO?usp=drive_link)

Certifique-se de que tem permissão de acesso. Em caso de dúvidas, entre em contato com a equipe (Lucas Teixeira).
